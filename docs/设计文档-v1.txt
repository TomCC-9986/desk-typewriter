桌面打字机（远程纸条）· 设计文档 v1
2026-11-11

================================================================
一、一句话
================================================================
装在 Mac / Windows 上的小程序。加了好友以后，我在自己屏幕底部的打字机上
敲一段话发出去，对方屏幕顶部就会一格一格吐下一张纸，逐字打出这段话。

================================================================
二、范围
================================================================
第一版要做：
  - 桌面 App（Electron，一套代码打包 Mac .dmg + Windows .exe）
  - 配对码加好友，必须对方同意
  - 发送：底部打字机，逐字打、纸往上走、撕纸后飞出屏幕
  - 接收：顶部出纸，逐行往下走、逐字打印，挂在屏幕顶上，可以拽下来贴到桌面
  - 离线暂存：对方不在线时消息存在服务器上，等他上线再打印
  - 托盘菜单：好友、我的配对码、历史纸条、勿扰、开机启动

第一版不做：
  图片 / 手写、群发、端到端加密（先靠 HTTPS/WSS）、手机端、
  实时同步打字（已确定用「发送后回放」）

================================================================
三、整体结构
================================================================

 发送方 App ──WSS──▶ Cloudflare Worker ──▶ 收件人信箱(Durable Object) ──WSS──▶ 接收方 App
                         (入口/配对)          (在线就推送，离线就存着)

1. 桌面 App（Electron）
   - main 进程：托盘、全局快捷键、窗口管理、WebSocket 连接、本地存储
   - 打字机窗口（发送）：屏幕底部居中，透明、无边框、置顶，用的时候才出现
   - 出纸窗口（接收）：屏幕顶部，透明、无边框、置顶、默认鼠标穿透，只有纸本身能点
   - 便签窗口：纸被拽下来以后，每张纸单独一个小透明窗口，可以贴在桌面任意位置
   - 设置 / 好友面板：一个普通小窗口

2. Cloudflare Worker（入口）
   - /register  第一次启动：生成 userId + 密钥 + 配对码
   - /ws        带密钥鉴权后连到自己的信箱
   - 配对码 → userId 的映射存在 KV（或一个专门的 Durable Object）

3. 信箱（每个用户一个 Durable Object）
   - 存：好友列表、待处理的好友请求、未投递的消息队列
   - 收到消息：检查发送方是不是好友 → 对方在线就直接推，不在线就入队
   - 对方连上来以后：按顺序把队列里的消息推过去，收到 ack 才删

================================================================
四、交互细节
================================================================
【发送 · 打字机】
  - 呼出：全局快捷键（默认 ⌘⌥P / Ctrl+Alt+P；⌘⇧P 会和 VS Code、Chrome 冲突）或托盘点「写纸条」
  - 屏幕底部升起一台打字机，上方露出一截白纸；先在顶部选好友（最近联系的人放第一个）
  - 每输入一个字：字锤动画 +「嗒」一声，字压到纸上（稍微有点歪、墨色深浅不一）
  - 一行写满或按 Shift+Enter：「叮」一声，滑架复位，纸往上推一行
  - 退格：回退一格，打错的字被划掉（保留打字机的痕迹）
  - 中文输入法：组字期间不打到纸上，上屏之后才逐字打出来
  - 上限 200 字，剩不多时纸边出现提示
  - 发送：Enter，或者拉一下右侧拨杆 → 纸被撕下（锯齿边）→ 往上飞出屏幕
  - 结果：打字机上方小字提示「已送达」或「对方离线，上线后打印」，然后打字机降下去
  - Esc：收起，草稿会保留

【接收 · 顶部出纸】
  - 消息到了：先响一声出纸提示音，屏幕顶边中间（位置可设置）露出打印口
  - 纸一格一格往下：每打完一行，纸往下顿一格（步进的机械感，不是平滑滑下）
  - 逐字打印的节奏固定（大约每字 60–90ms，稍微随机），每字配一声轻响
  - 纸尾打上「— 小王 14:02」，最后一下撕纸声，纸挂在屏幕顶上
  - 同时来好几条：排队一张一张打，打好的往旁边错开挂
  - 纸可以拽下来变成桌面便签；双击揉成团扔掉
  - 挂着的纸 30 分钟没人管 → 自动揉成团，沿弧线飞进废纸篓：
      Mac：飞向程序坞右端的废纸篓（根据程序坞在哪边、多大估算位置）
      Windows：飞向桌面「回收站」图标的位置（拿不到位置就飞向左上角）
    同时把纸条内容存成一个 .txt 放进系统废纸篓/回收站（用 shell.trashItem），
    真的能在废纸篓里翻出来；「历史纸条」里也会留一份
  - 被拽到桌面上的便签不会被自动扔掉
  - 勿扰模式：只在托盘图标上显示红点，关掉勿扰后再统一打出来

【加好友】
  - 托盘 →「我的配对码」显示 K7Q-29M 这种码，可以一键复制
  - 托盘 →「加好友」输入对方的码，再给自己起个对方能看到的昵称
  - 对方屏幕顶部吐下一张特殊纸条：「小王想和你互传纸条」[同意] [拒绝]
  - 同意以后双方都会收到确认；好友面板里可以删除、拉黑

================================================================
五、数据格式
================================================================
消息（App ⇄ 信箱，JSON）：
  { type:"note", id, from, to, text, sentAt }
  { type:"ack", id }
  { type:"friend_request", from, nickname }
  { type:"friend_response", from, accepted }
  { type:"status", id, state:"delivered"|"queued" }

本地（electron-store）：身份密钥、好友缓存、草稿、历史纸条（最近 200 条）、
                       设置（快捷键、出纸位置、音量、勿扰）

================================================================
六、出错怎么处理
================================================================
  - 自己断网：发送按钮变灰，提示「没连上服务器」，草稿不会丢；后台自动重连（指数退避）
  - 对方离线：消息入队，发送方看到「上线后打印」；队列里的消息最多存 7 天
  - 没加好友就发：服务器拒绝，App 提示
  - 刷屏：每个发送者每分钟最多 10 条；超出 200 字服务器也拒收
  - 消息重复：每条消息有 id，接收方去重以后才打印
  - 国内连不上 workers.dev：可以绑一个自己的域名，App 里能改服务器地址
